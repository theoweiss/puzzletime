# Resource Planning

Plan and manage team capacity with PuzzleTime's planning features.

## Overview

Resource planning helps you:

- Allocate team members to projects
- Visualize capacity and workload
- Identify bottlenecks
- Plan future work

## Accessing Planning

Navigate to **Planung** (Planning) in the main menu.

## Creating Plans

### Allocate Team Member

1. Go to **Planung**
2. Select employee
3. Select order/position
4. Enter hours per week
5. Set date range
6. Save

### Quick Allocation

From the planning grid:

1. Click on a cell
2. Enter hours
3. Cell updates

## Planning Parameters

| Field | Description |
|-------|-------------|
| Employee | Who to allocate |
| Order | Which project |
| Position | Specific position |
| Hours/week | Planned hours per week |
| Start date | When allocation begins |
| End date | When allocation ends |
| Definitive | Confirmed vs. tentative |

## Capacity Management

### Understanding Capacity

```
Available Capacity = Employment % × Weekly Hours

Example:
80% employment × 42 hours = 33.6 hours/week
```

### Capacity vs. Planned

| Status | Meaning |
|--------|---------|
| Under-allocated | Capacity available |
| Fully allocated | No free capacity |
| Over-allocated | Too much planned |

### Viewing Utilization

1. Go to planning view
2. See capacity bar per person
3. Color indicates:
    - 🟢 Green: Available
    - 🟡 Yellow: Near capacity
    - 🔴 Red: Over-allocated

## Definitive vs. Tentative

| Type | Use Case |
|------|----------|
| **Definitive** | Confirmed work |
| **Tentative** | Potential work, proposals |

Mark plans as definitive when:

- Contract is signed
- Work is confirmed
- Resources are committed

## Editing Plans

### Modify Allocation

### Move Allocation

## Planning Best Practices

### Regular Updates

- Review weekly
- Adjust for changes
- Remove completed work

### Buffer Capacity

Don't allocate 100%:

```
Recommended: 80-85% allocation
Buffer for: Meetings, support, unexpected work
```

### Tentative Pipeline

Keep tentative plans for:

- Sales pipeline
- Future phases
- What-if scenarios

## Integration with Time Tracking

### Adjusting Plans

When actuals differ:

1. Review variance
2. Update future plans
3. Document reasons

## Team Coordination

### Resolving Conflicts

When someone is over-allocated:

1. Identify the conflict
2. Prioritize orders
3. Redistribute or delay work
4. Update plans

### Vacation Planning

Account for absences:

1. Enter vacation in planning
2. Reduce capacity
3. Redistribute work

## Common Issues

??? question "Cannot see planning"
    - Check your permissions
    - Planning may require specific roles
    - Contact administrator

??? question "Over-allocation warning"
    - Review the person's allocations
    - Move or reduce hours
    - Consider other team members

??? question "Planned hours don't match"
    - Check date ranges
    - Verify order/position
    - Look for overlapping entries

### Communication

- Share plans with team

### Flexibility
